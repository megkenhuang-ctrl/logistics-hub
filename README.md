# 廠區物流時刻表資料庫戰情網 (Fab Fleet Timetable DB & Logistics Hub)

本系統已將廠區全車隊（Car A、Car B、Car C、Car D、Car E）所有時刻表轉換為正規化關係型資料庫（SQLite `logistics.db`），並建置了功能完整的戰情網站與 REST API，提供車班查詢、各 Fab 到站等候時間分析、指標統計總結表與即時 SQL 查詢終端。

---

## 🚀 快速啟動方式

### 方法 1：雙擊批次檔（最簡單）
在 Windows 檔案總管中，直接雙擊：
👉 **`啟動網站.bat`**
- 自動完成資料庫檢驗與更新。
- 自動在瀏覽器開啟 `http://localhost:5000`。

### 方法 2：命令列啟動
```bash
python server.py
```
開啟瀏覽器前往：`http://localhost:5000`。

### 方法 3：離線/免伺服器直接開啟
即便不安裝 Python 或未啟動後端，直接在瀏覽器雙擊開啟 **`index.html`**，系統會自動載入 `db_export.json` 完整資料，所有查詢、指標統計與圖表皆能正常運作！

## 🛠️ 核心功能一覽

### 1. 🚌 班車車班查詢 (Fleet Timetable Query)
- **車輛選擇器**：支援 Car A、Car B、Car C、Car D、Car E 以及「全部車隊」一鍵切換。
- **車班母站資訊卡**：即時顯示各車母站位置、隨車專線簡碼、單班目標運能（批次）與核心任務。
- **班別切換**：☀️ 日班 (07:35~19:35)、🌙 夜班 (19:35~07:35) 與 🕒 24 小時連續時間軸。
- **篩選與防呆**：支援模式篩選（專車、環廠、小環、外廠）、關鍵字全文搜尋、SOP 防呆指引，並可**一鍵匯出 CSV 表格**。

### 2. 🏭 Fab 廠區到站與等候時間查詢 (Fab Arrival & Wait Time)
- **廠區選單**：支援 FAB8AB、FAB8CD、FAB8E、FAB8F、FAB8S、嘉晶篤行、嘉晶創新。
- **核心指標看板**：
  - **平均等候時間 (班距 Headway)**：精確計算各班車到站時間間隔。
  - **預期等待時間 (Expected Wait)**：現場物料隨機抵達時的平均等車時間（約為班距之半數）。
  - **最短 / 最長班距區間**。
  - **總抵達班次與總運能供給**。
- **24小時到站時間軸視覺條**：以時間刻度標記車輛進站點，懸停可查看抵達時刻與目的地。
- **跨廠即時路徑規劃 (OD Route Finder)**：輸入起訖廠區，即刻顯示下一班可用車次、出發時間與預計抵達時間。

### 3. 📊 統計總結報表 (Master Summary Table & Charts)
- **全廠綜合指標表**：
  - 各廠 **被訪問次數** (車輛停靠抵達次數)
  - 各廠 **出發/發車次數** (載運出發趟數)
  - 各廠 **會診/互聯次數** (跨廠 OD 專線與物料交接班次)
  - 各廠 **平均等候時間 (分)**
  - 各廠 **總承載運能 (批次 Batches)**
  - 服務車輛清單 (Serving Fleet)
- **視覺化分析圖表**：
  - 被訪問次數 vs. 平均班距等候時間（柱狀/折線雙軸圖）
  - 各廠區運能佔比分析（甜甜圈圓餅圖）
- **OD 跨廠互訪流向矩陣 (From-To OD Heatmap)**：
  - 顯示所有廠區間對開的班次與總批次運能，並與最新需求矩陣 (`Demand_from_to.xlsx`：22 條走廊、全日 OD 需求合計 2,720 批、廠區 Sum 總計 5,294 批) 進行滿足率對比。

### 4. 💾 時刻表資料庫管理與 SQL 查詢終端 (DB Management & SQL Console)
- **正規化 SQLite 資料表**：
  - `cars`：車隊主表 (代碼、車牌號碼、母站、電話、運能、任務)
  - `fabs`：廠區主表 (代碼、名稱、位置、代表色、全日 OD 需求與 Excel Sum 總計)
  - `schedules`：時刻表明細 (236 筆，包含日夜班所有欄位、行車作業時間、防呆指令、SOP)
  - `demand_matrix`：需求矩陣 (22 筆，源自 `Demand_from_to.xlsx` 全日 24H 與單班 12H 基準需求)
  - `driver_roster`：2026年11月司機與車輛排班總表 (360 筆)
- **即時 SQL 查詢終端**：在網頁直接輸入標準 SQLite SELECT 語句並即時呈現結果，提供多組常用快捷按鈕。
- **1-Click 重構資料庫 (ETL Reset)**：點擊即可自動重新讀取來源時刻表並重建 SQLite 資料庫。

### 5. 🪪 2026年11月 司機與車輛排班看板 (Driver & Fleet Roster Hub)
- **全月 360 格位完整數位化**：涵蓋 2026/11/01～11/30 全月每日、日班/夜班雙時段、Car A～Car U 共 6 輛車之執勤排程。
- **當日執勤司機動態卡片**：隨日期與班別切換，即時呈現各車當班司機、編制（正班/IJM外包）、車牌與隨車電話。
- **16 位司機出勤排行榜**：各司機出勤班次、日夜班比例進度條、主責車輛與累計工時估算。
- **全月 30 天甘特排程矩陣**：可點選任意日期格位即時對焦定位。
- **一鍵匯出**：提供 `driver_roster_202611.xlsx`、`driver_roster_202611.csv`、`driver_roster_202611.json` 多格式下載。
